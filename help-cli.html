CLI · 脚本运行

核心命令

  • jvav_dk27.exe：进入交互式 REPL，支持全部 160+ 倒序函数。
  • jvav_dk27.exe -c "tnirp('hi')"：执行单条命令后退出。
  • jvav_dk27.exe -f <file.jvav>：运行脚本文件，支持函数定义、类、控制流。
  • jvav_dk27.exe info：显示版本与功能信息。

REPL 使用

直接运行 jvav_dk27.exe 进入交互式环境，支持 def 函数定义、class 类定义、所有控制流语句。输入 quit 或 Ctrl+C 退出。

调试技巧

  • 脚本运行出错时，解释器会输出行号与错误信息。
  • 使用 plugin list 查看已加载插件。
  • 遇到延迟：关闭非必要插件，确认本地防病毒未拦截 CLI。

扩展函数支持

解释器内置 160+ 倒序函数，如 nus（求和）、xam（最大值）、nioj（连接）等，便于复杂逻辑表达。
