关于 JVAV · 真正的脑波原生语言

我们在做什么

JVAV 是一个真实、可验证的编程语言项目：用 Python 实现解释器，把「倒序命名」的内置函数作为语言的标志性设计。它拥有完整的运行时、包管理器、示例库与发布站点，所有环节都能独立校验。

当前版本：DK 27 v6 · Turing 完备 · 160+ 倒序函数 · 19 项自动化测试全部通过。

为什么叫「脑波原生」

「脑波」是 JVAV 的世界观——思维是语言的第一公民，代码是思维的忠实记录。我们相信编程可以像脑波一样自然流动，而工程严谨（沙箱安全、哈希验证、可复现构建）则是这一切的地基。

奇幻不等于虚假：仪式感留在故事里，工程事实落在哈希与测试上。

设计准则

  • 极简：界面居中留白，任何元素都为清晰传达服务
  • 可信：每个发行附带 SHA256，任何人都能复现校验
  • 可交付：一次构建，双击即用的 Windows 单文件 exe

语言与工具链

倒序函数库

160+ 倒序命名的 Python 内置函数：tnirp（print）、mus（sum）、nel（len）、egnar（range）、tcid（dict）。覆盖 I/O、类型转换、容器、数学、字符串、迭代器、位运算等全部标准库领域。

函数文档

Turing 完备

完整支持函数与类定义、if/elif/else、for/while、try/except、列表推导、递归。倒序关键字（fi/rof/nruter）与倒序布尔常量（eurT/eslaF）。任何可计算的算法都能表达。

安全沙箱

所有代码在 SafeEvaluator 中执行：AST 验证拦截 Lambda、dunder 访问、属性调用与危险导入。包与脚本均受同一套沙箱约束，防止恶意注入。

插件系统

7 个内置插件（文件、网络、日期、数学、控制台、系统、集合）按需加载；通过 jvavpkg 安装的库/插件包会被解释器自动发现，plugin load 即可复用。

包管理器 jvavpkg

基于 GitHub 仓库文件分发：一包一仓库、Git tag 即版本、>100MB 走外链并强制 SHA256。支持依赖解析、版本约束、循环与冲突检测，安装到全局或项目本地。

包管理器指南

发布与验证

PyInstaller 与 Nuitka 双打包（Nuitka 版体积小约 24%、启动快约 50%）。所有下载页哈希与源码级脚本（verify_production_status.py / report.py）保持一致，发布可复现。
