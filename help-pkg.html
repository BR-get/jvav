快速上手 包管理器 CLI 运行 脑波协议 安全与验真

0. 快速入门（30 秒）

  1. 下载 jvavpkg.exe（下载页）或使用 python src\jvavpkg.py。
  2. 安装一个包：jvavpkg install BR-get/two_sum
  3. 查看已装包：jvavpkg list
  4. 查看包信息：jvavpkg info BR-get/two_sum
  5. 在解释器里加载包：jvav_dk27.exe → plugin load two_sum（library/plugin 包自动被发现）

所有命令都以 owner/repo 或已注册的短名称引用包。匿名使用 GitHub API 限流 60 次/时，设置 GITHUB_TOKEN 提升至 5000 次/时。

一、使用教程

1.1 安装与卸载

# 全局安装（默认，装到 ~/.jvav/packages/）
jvavpkg install BR-get/two_sum

# 安装到当前项目（装到 ./.jvav/packages/）
jvavpkg install BR-get/two_sum --local

# 指定版本安装
jvavpkg install BR-get/two_sum --version v1.0.0

# 用短名称安装（首次安装后自动注册别名）
jvavpkg install two_sum

# 卸载（默认全局，加 --local 卸项目）
jvavpkg uninstall two_sum

卸载后 lock 同步更新；registry 别名保留，重新安装可直接用短名。

1.2 更新与查看

# 更新所有已装包到最新兼容版本
jvavpkg update

# 只更新指定包
jvavpkg update two_sum

# 列出已装包
jvavpkg list
jvavpkg list --local

# 查看远端包信息（版本/类型/依赖/资产）
jvavpkg info BR-get/two_sum

update 尊重安装时记录的版本约束（lock 中的 constraint 字段），不会越界升级。

1.3 依赖管理

包可在 jvavpkg.json 中声明依赖。安装时自动解析并安装所有依赖：

# jvavpkg.json（app 包依赖 jvav-utils）
{
  "dependencies": {
    "BR-get/jvav-utils": ">=1.0.0,<2.0.0"
  }
}
  • 版本约束：支持 >=、<=、>、<、== 及逗号组合
  • 循环检测：A→B→A 会报错 Circular dependency detected
  • 冲突检测：与已装版本不兼容时报 Version conflict

二、包格式规范

2.1 仓库布局

一包一仓库，Git tag = 版本。构建产物直接放仓库：

github.com/<owner>/<repo>
├── jvavpkg.json                  # 清单（根目录，随 tag 版本化）
├── jvavpkg.links                 # 超 100MB 资产外链清单（可选）
└── dist/
    ├── <name>-<ver>-win64.exe      # program 二进制
    └── <name>-<ver>-src.jvavpkg    # library/plugin 源码包

GitHub 单文件硬上限 100MB，超限资产必须走 jvavpkg.links 外链。

2.2 jvavpkg.json 字段

{
  "name": "two_sum",
  "description": "两数之和解法",
  "type": "plugin",              // program | library | plugin
  "author": "BR-get",
  "license": "MIT",
  "version": "1.0.0",
  "dependencies": {
    "BR-get/jvav-utils": ">=1.0.0"
  },
  "assets": {
    "win64": {
      "program": "dist/two_sum-1.0.0-win64.exe",  // type=program 时使用
      "source":  "dist/two_sum-1.0.0-src.jvavpkg" // library/plugin 时使用
    }
  }
}
字段必填说明
name是包名，也是安装目录名与 registry 别名
type是program→装到 bin/；library/plugin→解包到 src/
assets.win64是至少提供 program 或 source 一个路径
dependencies否依赖键建议用 owner/repo；短名需已注册
version否供参考；实际版本以 Git tag 为准

2.3 jvavpkg.links 外链格式

每行：文件名<TAB>SHA256<TAB>URL。命中清单的资产从外链下载并强制校验 SHA256：

# 文件名      SHA256(小写64位)                    URL
big-assets.dat  4d31b3d89f8a7c2b5e6f1a0c9d8e7f6a...  https://cdn.example.com/jvav/big-assets.dat

2.4 源码包 .jvavpkg 格式

源码资产是 JSON 文件，files 字典包含所有源文件内容（与 DK26/DK27 的 .jvavpkg 格式一致）：

{
  "name": "two_sum",
  "version": "1.0.0",
  "jvav_version": "DK27",
  "main": "two_sum.jvav",
  "files": {
    "two_sum.jvav": "# 两数之和...\n"
  },
  "build_info": {
    "timestamp": "2026-08-10T00:00:00Z",
    "builder": "jvavpkg",
    "platform": "windows-x64"
  }
}

安装后 files 中的每个文件按路径解包到 packages/<name>/src/。

三、命令参考

全局选项

选项说明
--local作用于当前项目（./.jvav/），默认全局
--version <tag>info/install 指定 Git tag（默认 latest）
--token <token>GitHub token（或环境变量 GITHUB_TOKEN）

info <name|owner/repo>

查看远端包信息：名称、仓库、版本、类型、依赖、资产。

jvavpkg info BR-get/two_sum

install <name>

安装包（含依赖解析）。可选 --version、--local、--token。

jvavpkg install BR-get/two_sum
jvavpkg install two_sum --version v1.0.0 --local

uninstall <name>

卸载包并更新 lock。name 为已装包名。

jvavpkg uninstall two_sum
jvavpkg uninstall two_sum --local

list

列出已装包（名称、版本、类型、来源）。可选 --local。

jvavpkg list
jvavpkg list --local

update [name]

更新已装包到最新兼容版本（尊重 lock 中的约束）。不带 name 则全部更新。

jvavpkg update
jvavpkg update two_sum

pack [src]

把本地 *.jvav 源文件打包成标准 .jvavpkg，替代手工脚本。

# 在项目目录内打包（自动选 main.jvav，输出 dist/<name>-<ver>-src.jvavpkg）
jvavpkg pack .
jvavpkg pack . --name two_sum --version 1.2.0 --main two_sum.jvav

产物格式与 DK26/DK27 的 .jvavpkg 兼容（files/main/build_info），可直接被解释器运行或经 install 分发。

退出码

码含义
0成功
1错误（包不存在 / 版本冲突 / 循环依赖 / SHA 不匹配 / 网络失败 / 401 限流）

四、安装目录与状态文件

~/.jvav/                     # 全局
├── packages/<name>/          #   manifest.json + src/（库/插件）或 bin/（程序）
├── registry.json             #   短名别名 → owner/repo
└── jvavpkg.lock.json         #   已装包快照（版本/约束/来源）

./.jvav/                     # 项目本地（--local）
├── packages/<name>/
└── jvavpkg.lock.json

lock 文件固化解析结果，保证可重现安装。示例包 BR-get/two_sum 已发布 v1.0.0，可直接体验。
